# منصة رائد النشاط — مدارس الأندلس الأهلية

منصة إدارة ريادة النشاط الطلابي (القسم الثانوي — بنين).
إعداد: عبدالله محمد القرني

## بنية الملفات

```
index.html                      الصفحة الرئيسية (نقطة الدخول)
assets/
  ├── style.css                 كل تنسيقات المنصة وألوان الهوية
  ├── app.js                    كل منطق المنصة والبيانات الافتراضية
  ├── logo-color-mark.png       الشعار الملون (الرمز فقط)
  ├── logo-color-lockup.png     الشعار الملون كامل (رمز + نص)
  ├── logo-white-lockup.png     الشعار الأبيض كامل (للخلفيات الكحلية)
  └── logo-white-mark.png       الشعار الأبيض (الرمز فقط)
```

## التشغيل

افتح `index.html` بأي متصفح (Chrome / Safari / Edge). لا يحتاج أي تثبيت أو خادم.

**مهم:** يجب أن يبقى مجلد `assets` بجانب `index.html` دائمًا، وإلا لن تظهر الشعارات والتنسيقات.

## الرفع كموقع برابط دائم

ارفع **المجلد كاملًا** (وليس `index.html` وحده) على أي استضافة ثابتة مثل
Netlify Drop أو GitHub Pages أو Cloudflare Pages.

## حفظ البيانات

تُحفظ البيانات (المهام، الخطة، المسابقات، الطلاب، الشواهد) داخل متصفح الجهاز نفسه.
كل جهاز أو متصفح له نسخته الخاصة، ولا تتزامن البيانات تلقائيًا بينها.

## أقسام المنصة

- **اليوم** — لوحة سريعة لفعاليات ومهام اليوم
- **الرؤية** — الرؤية والرسالة والخطة الأسبوعية (36 أسبوعًا)
- **الجدول** — الجدول الأسبوعي المتكرر
- **التقويم** — تقويم سنوي (عرض شبكة / عرض جدول)
- **المسابقات** — متابعة المسابقات والأولمبيادات والطلاب المسجلين والشواهد
- **التقارير** — تقرير أسبوعي وشهري جاهز للطباعة أو النسخ
- **المهام** — إدارة المهام مع رفع شواهد الإنجاز
- **التنبيهات** — المواعيد القريبة والمتأخرة
